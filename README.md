# The SaaSpocalypse: How to Win in the Next Decade

Luke Stanke · Big Data LDN 2026

A single-file HTML presentation. No build step, no dependencies to install.

**Live:** https://luke-at-sigma.github.io/saaspocalypse/

## Running it

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

## Driving it

| Key | Action |
| --- | --- |
| `→` / `space` | Next beat |
| `←` | Previous beat |
| Grid button (top right) | Jump to any beat |

Every beat has its own URL (`#33-takeaway-dashboards-apps-and-agents`), so any
point in the deck can be linked to directly.

## Notes

- Demo videos stream from Wistia and need a network connection.
- The display font is DM Sans, loaded from Google Fonts. Advercase is declared
  in `@font-face` but its files are not in this repo — it is a licensed
  typeface and nothing currently renders in it.
